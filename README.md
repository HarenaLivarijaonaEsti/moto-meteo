# moto-meteo
# 🏍️ Moto Weather AI

Application météo intelligente destinée aux motards.  
Elle analyse les conditions météo et fournit des conseils de conduite, y compris une interprétation par IA (Gemini).

---

## 🚀 Fonctionnalités

- Recherche de météo par ville
- Géolocalisation automatique (OpenStreetMap Nominatim)
- Données météo via API 7Timer
- Analyse météo lisible (texte humain)
- Recommandations pour motards :
  - vêtements adaptés
  - conditions de conduite
  - utilisation de lunettes de soleil
- Analyse intelligente via Gemini AI 
- Interface mobile avec animations

---

## 🧠 IA (Gemini)

L’application utilise Gemini pour :
- donner un avis orienté sécurité moto
- produire un résumé compréhensible



## 📦 Technologies utilisées

- Node.js
- Express.js
- EJS
- Axios
- Luxon
- tz-lookup
- Gemini API (Google AI)
